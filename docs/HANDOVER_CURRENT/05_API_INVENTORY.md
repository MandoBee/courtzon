## Notes on the API surface

- Global `preHandler: authMiddleware` protects every route except explicitly public ones (e.g. auth/register/login/refresh, health, payments/webhook, public tournaments).
- Org-scoped endpoints appear in multiple files (e.g. `org-portal.routes.ts` carries the /org/:orgId surface).
- Auth-token: HttpOnly session cookie; Bearer also accepted for API clients (documented in app.ts swagger description).
- Idempotency: payments are idempotent (idempotency_key + gateway_reference uniques). Generic mutations are not.
- Error shape: `{ error, message, code, meta: { requestId, timestamp }, details? }` via AppError / zod / rate-limit / 500 handler.
