## 1. الملخص التنفيذي

نُفِّذت محاكاة تشغيلية فعلية على التطبيق الحقيقي (HTTP API + قاعدة البيانات + واجهة React + Docker)، وليس على اختبارات وهمية. أُنشئت بيانات اختبار موسومة بـ `SIM-FINAL` (100 لاعب، منظمتان، 3 أسواق، ملاعب بادل وتنس، 4 بطولات، 3 أكاديميات). نُفِّذت **80 حالة اختبار مسجلة**: **79 PASS**، **1 FAIL** معروف ومُوثَّق، إضافة إلى 5 عيوب تم اكتشافها وإصلاحها والتحقق منها بعد الإصلاح.

أهم النتائج الإيجابية:

- 20 حجزًا نُفِّذت بنجاح (فردي/جماعي، بادل/تنس، نقدي/بطاقة) مع منع الحجز المزدوج (409) وسباق تزامن 5 لاعبين أنتج حجزًا واحدًا فقط.

- 4 بطولات أُكملت بالكامل (7 مباريات خروج مغلوب ×2، 28 مباراة دوري ×2) مع اعتماد النتائج وتدرج الأدوار.

- الميزان التجريبي للمنظمة A: مدين = دائن = 51,218.00 جنيه.

العيب المفتوح الوحيد (متوسط): حجز نقدي **غير مدفوع** ثم يُلغى خارج نافذة الإلغاء يسجل `refunded_amount` بقيمة الحجز رغم عدم تحصيل أي نقد (القيد المحاسبي نفسه متوازن ويُعكس بالكامل، لكن دلالة العمود مضللة).

## 7. الأسباب الجذرية والإصلاحات

1. **سباق webhook/التأكيد:** `_createFromPrepare` كان يؤكد الحجز فقط عند وصول الدفع مسبقًا، دون إعادة إصدار نتيجة الدفع، فلا تُحدَّث `payment_status` ولا تُنشر القيود. أُضيف بث `payment:succeeded` بعد ربط المعاملة وإعادة تعيين الحالة إلى `paid`.
2. **رسوم الإلغاء:** `_calculateCancellationFee` كان يقرأ فقط جدول `cancellation_policies`، بينما شاشة المنظمة تكتب أعمدة `organisations.cancellation_*`. أُضيف fallback آمن.
3. **RBAC اللاعب:** نمط `PLAYER_PATTERNS` كان يطابق `marketplace.cart` وليس `marketplace.cart.view`. وُسِّع النمط ومنحت الصلاحيات للدور.
4. **إعادة المحاولة:** استُخدم نوع `custom` دون تسجيل `settings.backoffStrategy` في Workers. سُجِّل في `worker.ts` و`subscriber.worker.ts`.
5. **/my/scopes 401:** محاولة قراءة النطاقات قبل تثبيت كوكي الجلسة. أُضيفت إعادة محاولة واحدة (350ms).

5. **حجب Paymob الحقيقي:** المفتاح العام الحالي يرفضه Paymob (`Unable to authenticate this public key`) — يلزم تصحيحه من لوحة Paymob قبل قبول الدفع.
6. Playwright أُعيد تشغيله بعد بناء الواجهة: 4/4 + 2/2 smoke PASS.
7. لم تُختبر بوابات دفع أخرى (فودافون كاش/فوري) أو SMS/WhatsApp فعليًا.
