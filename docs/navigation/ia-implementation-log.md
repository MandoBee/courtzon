| Commit 12 (regression fix #2) | All | **Player infinite-render regression: unstable `can` reference in `useCan` caused CommandPalette effect loop.** When `searchModule` loaded after search opened, the effect `[searchModule, t, can, flags]` had an unstable `can` dependency — `useCan()` returned a new function reference every render without `useCallback`. Combined with `setAdminCommands(newArray)` (new array reference each call), this caused an infinite render loop saturating the main thread (RAM ~97%), making all UI unresponsive. Fix: wrapped `can` in `useCallback(can, [permissions])` — stabilizes reference when permissions unchanged. `t` (from `useTranslation`) and `flags` (from zustand selector) were already stable. No architecture changes. Tests: 115 → **117** (2 new ref-stability tests). CI baseline: 222 unchanged. | RBAC-by-Default Engineering Standard | None |
